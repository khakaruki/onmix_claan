OMNIX CLAN — ИСПРАВЛЕННЫЙ САЙТ

В этой версии стили встроены прямо в каждый HTML-файл, поэтому оформление не пропадёт,
даже если style.css не загрузится. Фоновый баннер хранится в папке assets.

ВАЖНО: загружайте содержимое этого архива, а не сам ZIP:
- index.html
- rules.html
- administration.html
- activity.html
- rests.html
- schedule.html
- shop.html
- папку assets целиком

На GitHub:
1. Repository → Code → Add file → Upload files.
2. Перетащите ВСЕ перечисленные файлы и папку assets.
3. Commit changes.
4. Settings → Pages → Deploy from a branch → main → /(root).

Проверьте, что в корне репозитория видны index.html и папка assets.
Внутри assets должен быть omnix-angel-demon-banner.png.
